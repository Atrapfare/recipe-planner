# 🚀 Frontend (Vue.js)

1. **Install Dependencies**:  
   Navigate to the frontend folder and run:
   ```bash
   npm install
   ```

2. **Start Development Server**:  
   Start the Vue.js development server:
   ```bash
   npm run dev
   ```

3. **Build**:  
   Build the frontend for production:
   ```bash
   npm run build
   ```
