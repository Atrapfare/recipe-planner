# 🚀 Backend (Spring Boot)

**Start backend for development**:
1. Navigate to the backend folder and build the project:

   ```bash
   mvn spring-boot:run
   ```

**Clean backend**:
2. Cleans the project:

   ```bash
   mvn clean
   ```

**Build backend**:
3. Build the backend as .jar for production:

   ```bash
   mvn clean package
   ```
